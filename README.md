# pio-game
A game about Pio, the chick.

## 📝 Descrição do Projeto
**pio-game** é um jogo de plataforma arcade desenvolvido no **Game Maker**. O jogador assume o controle de Pio, um pintinho recém-nascido que tem um grande objetivo: comer milho o suficiente para crescer e se tornar uma galinha, enquanto desvia de perigos que tentam impedir sua jornada.

## 🎯 Objetivo
O objetivo principal é acumular o máximo de pontos possível consumindo "sementes" (milho) que surgem aleatoriamente ou em locais estratégicos durante a fase. Além das sementes, haverá outras funcionalidades para pontuação extra.

## 🐣 O Personagem: Pio
* **Nome:** Pio, o pinto.
* **Evolução:** Uma das características centrais da gameplay é o crescimento ou evolução do personagem no decorrer da partida.

## 🕹️ Mecânicas e Poderes
O jogo conta com movimentação fluida de plataforma:
* **Movimentação Básica:** Andar, pular e descer (fast drop).
* **Upgrade:** Pulo duplo (Double Jump) disponível como uma melhoria adquirida durante o jogo.

## 🦅 Obstáculos e Inimigos
* **Ovo:** Um obstáculo/item que "suga" o jogador, dificultando a movimentação.
* **Inimigo Aéreo (Águia):** Um animal voador ( uma aguia literal lol) que mergulha em direção ao Pio para tentar capturá-lo.
* **Obstáculos de Cenário:** Elementos que impedem o avanço e devem ser eliminar o jogador com uma bicada ou desviados.

## 🛠️ Tecnologias Utilizadas
* **Engine:** Game Maker
* **Linguagem:** GML (GameMaker Language)
